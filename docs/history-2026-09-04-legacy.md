### 해결된 것 — 다시 밟지 말 것

**옛 `503` 스톨(1,101/1,323에서 6/6 실패)의 원인은 상태 값 비대가 맞았다.**
`sync:state`에 누적 카드를 통째로 담아 약 1.7MB까지 커졌고, 매 단계 그걸 파싱·직렬화하다
무료 요금제 CPU 10ms를 넘겼다. 인덱스+버킷으로 쪼개 값 크기를 유계로 만든 뒤 **같은
지점을 그냥 통과해 1,323까지 갔다** — 가설이 반증되지 않고 확인된 것.

**카드 본문은 이제 Notion 원본 블록으로 보관한다**(평문 문자열 배열 폐기). 렌더는 표시
시점에 클라이언트가 한다 — 그래서 **앞으로 렌더링을 몇 번 바꾸든 재동기화가 필요 없다.**

⚠ 카드별 개별 KV 저장은 여전히 불가 — 무료 **KV 쓰기 1,000회/일** 제한에 1,323장이 걸린다.
⚠ 파서를 바꾸면 카드의 `parserVersion`을 올릴 것. 증분 로직이 그 값이 다르면 재사용하지
않고 다시 긁는다(현재 `2`). 이게 없으면 옛 포맷이 영원히 살아남는다.

**`undoGrade`의 스코프 버그(2026-09-04 실조건 테스트로 발견·수정)** — `n`·`step`을
`try` 블록 안에서 `const` 선언해 놓고 블록 밖 `return`에서 참조해, 되돌리기를 호출할
때마다 `"n is not defined"` 500 에러가 났다. 채점 재설계 이전부터 있던 결함(3단 채점
시절 코드도 같은 구조)인데 그동안 실사용에서 되돌리기를 실제로 호출해 본 적이 없어
안 걸렸던 것으로 보인다 — `n`/`step` 선언을 `try` 밖으로 옮겨 해결.

끌 땐 화면폭의 50% 이상, 빠르게 튕기면(300ms 안에 18% 이상) 짧은 거리로도 커밋. 옛 고정
px(`TH`) 방식은 화면이 크면 살짝만 끌어도 넘어가버리는 문제가 있어 폐기. 코드는
확인했지만("자체확인") 실기기 체감 검증 전.

⚠ 좌우 스와이프와 Safari 뒤로가기 제스처는 거의 간섭하지 않는다 — iOS 뒤로가기는
**화면 좌측 끝에서 시작**해야 걸리고, 우리 제스처는 중앙에서 시작한다(2026-09-03 확인,
단일화면이 돼도 여전히 유효).

### 화면 구성

- **최상단 줄**(카드와 무관, 드래그해도 안 움직임): 오늘 카운터(중앙 — 오늘 "본" 고유
  카드 수, 채점 여부 무관. 세션 진행 중엔 `n/total`로 바뀜) + 생성일(우측, 차수색 배지).
  우상단은 시선이 잘 안 가서 상단 정보를 여기로 몰았다(2026-09-04 사용자 판단).
- 그 아래 제목(크게, 좌우 드래그 시 본문과 같이 이동) — 항상 최상단 근처 고정은 유지.
- 본문 인라인 코드(사용자가 브라우저 확장으로 친 형광펜) = **코랄 실색 배경 + 어두운
  텍스트**("하이라이터 반전" — 코랄 텍스트를 코랄 배경 위에 얹던 이전 안은 대비가 낮아
  폐기, 실측 대비비로 확인).
- **강조색은 코랄 하나로 통일**(표 헤더, 시트 활성 탭, 슬라이더 손잡이 등). 예전에 쓰던
  gold는 그 의미(진행 게이지·다시 만남 보너스 테두리)가 이번 재설계에서 다 빠져서 폐기.
  차수(0/1/2/3차) 표시만 예외로 회색/파랑/주황/빨강 4색 유지 — 카테고리 4개를 단색으로
  못 나타내서("다른 색이 꼭 필요한" 경우로 판단).
  ⚠ **캘린더 개수 숫자는 예외**(2026-09-04 `design-bakeoff` 라운드3 확정, `prototype.html`
  반영 완료) — 코랄은 "오늘" 칸 테두리(링+글로우)에만 쓰고, 개수 숫자 자체는 밝은 흰색
  (`--paper`, `font-weight:300`)으로 뚜렷하게: 강조색을 "값 표시"가 아니라 "의미 있는
  상태"에만 쓴다는 원칙(`~/.claude/design-system/preferences.md`)과 맞춘 것 — 흰색도
  코랄(강조색)은 아니라서 원칙 자체는 안 깨짐. 칸 모양은 그림자·그러데이션 없는 플랫
  (`border-radius:5px`, `background:var(--ink3)`). 상세: `~/.claude/design-system/
  projects/shorts-deck.md`.
- 완료 성공 시 버튼이 짧게 펄스. 세션(날짜별/목록 복습)이 끝나면 짧은 완료 카드(체크
  아이콘 + "오늘 N개 복습 완료", 0.9초) 후 평소 화면 복귀.
- 2단이 없어졌으므로 글자 크기 조절은 **제목/본문 따로**(하단 시트 최상단 슬라이더),
  값은 `localStorage`에 저장돼 다음 접속에도 유지.

⚠ 채점이 완전히 버튼 전담이라 롱프레스 시 iOS 텍스트 선택 팝업이 뜰 수 있다 — 카드
영역엔 `-webkit-touch-callout:none` 유지, 본문 텍스트는 선택 가능해야 하므로 예외.

⚠ **iOS Safari `position:fixed;inset:0`은 주소창이 떠 있을 때도 큰 뷰포트 기준으로
높이를 잡는 경우가 있다**(2026-09-03 실기기 스샷에서 확인) — `#app`에 `height:100dvh`를
유지할 것. 단일화면 재설계 이후 재확인은 안 함.

### 하단 시트(모아보기) — 우측 레일 ☰로 열림

⚠ **진입점은 이거 하나뿐이다.** 예전엔 "오늘 카운터 꾹 누르면 열림"이라는 숨은 경로가
있었는데, 사용자가 그걸 몰라서 "캘린더가 안 보인다"는 버그로 오인한 적이 있어 없앴다
(2026-09-04).

- 항상 **캘린더가 기본**. 실제 날짜 그리드(일~토 정렬), 각 칸 좌상단에 날짜 숫자,
  중앙에 그날 본 개수(밝은 흰색, 0이면 숫자 자체를 안 그림 — 위 "코랄은 오늘 칸에만"
  참조). 배경 농도로 개수를 또 표현하지 않는다(숫자 하나로 충분하다는 판단). **최근 4주 고정 창** — 그 이전 기록은 캘린더에
  안 뜨고 검색/차수탭으로 찾는다(캘린더=최근 리듬, 검색/탭=전체 아카이브로 역할 분리.
  무한 과거 스크롤은 기각 — 부채감 없는 자유 탐색을 우선하는 방향과 같은 이유, 아래
  "메인 덱 공급 규칙" 참조).
- 날짜(오늘 포함)를 누르면 그 자리가 **그날 본 카드 제목 목록**으로 바뀐다(같은 자리
  토글, `← 캘린더`로 복귀). 오늘 칸은 0개여도 눌러서 빈 상태를 볼 수 있다.
- 검색 + 전체/0/1/2/3차 탭도 같은 자리(`#calArea`)를 공유 — 전체 DB 대상, 탭 재클릭하면
  해제돼 캘린더로 돌아간다.
- **목록에서 아무 항목이나 고르면 그 지점부터 순차 복습 세션이 시작된다**(맨 위=처음부터,
  다른 항목=거기서부터). 캘린더 날짜 클릭도 같은 세션 메커니즘을 쓴다.
- 시트를 아래로 스와이프하면 닫힌다(리스트/캘린더 스크롤이 맨 위일 때만 반응 — 스크롤
  중엔 안 뺏김. 손잡이 영역은 항상 반응).

✓ **캘린더의 "지난 날짜" 목록·개수는 실제 데이터다**(2026-09-04 이식 완료) — 서버가
`GET /api/calendar`(최근 N일 개수)·`GET /api/day?date=`(그날 채점된 카드 목록)로 내려준다.
위 "현재 상태" 섹션의 "캘린더가 실제 데이터를 쓴다" 참조.

### 메인 덱 공급 규칙 — 서버 쪽, 실조건검증 완료

`GET /api/cards`(`handleCards`/`pickByDate`, `src/worker.js`)가 끝없는 연습 큐를 채운다.

- **생성일자 오름차순(오래된 것부터)이다**(2026-09-04, 사용자가 Notion에서 쓰던 방식
  그대로 요청 — `완료도 0` 70%+복습 때 된 것 30% 가중치 뽑기와 정통 간격반복 기반 "때가
  됨" 경과일 로직(`1차 3일·2차 7일·3차 21일`)을 전부 폐기하고 대체했다). 클라이언트가
  마지막으로 받은 카드의 `created`를 `sd_cursor`(localStorage)에 저장해 `after` 쿼리로
  보내고, 서버는 그 지점 다음부터 이어서 `n`개를 준다 — 끝에 닿으면 처음으로 되감는다
  (고리형, 기존 덱 순환과 같은 정신). 그래서 다음 접속 때도 어디까지 봤는지 이어진다.
  ⚠ 이 순서는 완료도(step)·복습 상태와 완전히 무관하다 — 이미 3차까지 끝난 카드도 자기
  차례가 오면 그대로 다시 보여준다(의도된 동작. "구분 자체를 없앤다"가 사용자의 명시적
  요청이었음).
- ⚠ **인덱스 항목에 `created`가 있어야 정렬이 된다** — 이 필드는 2026-09-04에 추가돼서,
  그 이전에 동기화된 인덱스에는 없다. 새 배포 직후 `/api/sync?restart=1`로 강제 재동기화
  한 번 필요(그 시점에 이미 실행함 — `parserVersion`은 안 올렸으므로 카드 본문 재수집은
  없고, 행 목록만 다시 훑어 인덱스를 재구성한다. 버킷은 대부분 재사용돼 빠르다).
- **메인 게이지(완료도=0 잔량 표시)는 폐기했다**(2026-09-04) — 0차가 1,000장을 넘어가면
  숫자가 줄어드는 게 안 보여서 의미가 없어졌다. 그 자리는 위 "오늘 카운터 + 캘린더"가
  대신한다.

⚠ **iOS Safari에는 진동/햅틱 API가 없다**(iOS 26.5에서 `<input switch>` 우회도 막힘).
보상 피드백은 색·모션·소리로만 설계한다(2026-09-04: 완료 버튼 펄스·세션종료카드가 이
역할). 햅틱이 꼭 필요해지면 그때 Capacitor로 감싼다(Apple Developer $99/년 — 그 전엔
낼 이유 없음).
