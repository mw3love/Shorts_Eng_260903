## 이번 세션에서 한 일

`prototype.html`(Artifact 목업, https://claude.ai/code/artifact/2e4bf9a7-a6ca-49c4-965d-aef36aa71106)에서:

1. **스와이프 커밋 판정 재작성** — 고정 px(`TH`) 방식을 폭 비율+속도 하이브리드로 교체.
   `COMMIT_RATIO=0.5`(천천히 끌 땐 폭의 50% 이상), `FLICK_MS=300`+`FLICK_RATIO=0.18`(빠르게
   튕기면 짧은 거리로도 커밋). `DRAG_SENS`도 2.5→1.15로 낮춤(커밋 기준이 폭 비율이라 시각
   증폭을 따로 키울 이유가 없어짐). 근거: Swiper.js `longSwipesRatio`/`longSwipesMs`,
   Material Design 3 duration 토큰(둘 다 공식문서 확인함).
2. **전환 애니메이션 재작성** — 예전엔 `-40px`만 움직이고 `setTimeout` 160ms 뒤 즉시 컷하는
   방식이라 "살짝 후퇴 후 순간 교체"처럼 뚝뚝 끊겼음. 카드 폭만큼 완전히 슬라이드시키고
   `transitionend` 이벤트로 정확한 타이밍에 스왑하도록 교체.
3. **프리뷰(옆 카드) 밝기 통일** — `opacity:.5`+`color:var(--muted)`로 옅게 죽이던 것 제거.
   스왑 순간 위치(4px 패딩 어긋남도 같이 발견해 수정함)+밝기가 동시에 튀어 보이던 게 원인.
4. **오늘 카운터 시드 버그 수정** — `MAIN_DECK_IDS` 6장 전부를 `todaySet`에 시드해서 스와이프로
   돌아도 항상 이미 "본" 카드뿐이라 숫자가 절대 안 늘어나던 버그. 절반만 시드하도록 수정.
5. **`design-bakeoff` 스킬로 하단 시트 디자인 2라운드 진행, 확정됨**:
   - 캘린더: 둥근 모서리(`radius:10px`)+은은한 그림자(`box-shadow`)+코랄 테두리(오늘 칸만).
     단, **개수 숫자 굵기를 650(볼드)에서 400~500 정도로 낮출 것** — 사용자가 "볼드만 빼면
     좋겠다"고 확정 피드백을 줌.
   - 슬라이더 바: 지금처럼 숫자(%)만 표시하는 방식 그대로 확정. 트랙만 pill 모양+코랄 채움으로
     다듬기. 실시간 텍스트 미리보기 안(S2)은 "실제 앱에선 시트 위에 이미 제목·본문이 보이니
     중복"이라는 이유로 탈락.
   - 확정 토큰 전체(정확한 hex·px 값)는 `~/.claude/design-system/projects/shorts-deck.md`에
     있음 — 코드 반영 시 그대로 옮기면 됨, 새로 디자인할 필요 없음.
6. `CLAUDE.md` doc-sync 완료·커밋함(코드 변경과 같은 커밋).
